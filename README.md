# bSpine

bSpine is a demo healthcare case-management web application for a legal team (a law firm handling
personal-injury and spine-injury claims). It tracks the **medical side** of each legal case: claimants,
cases, medical providers, treatments and bills, medical records requests, and case notes.

> **Demo data only.** All people, providers, case numbers and amounts are fictional and generated by the
> seed routine. The app contains **no real PHI** and must not be used to store real patient or client data.
> It uses an in-memory database with no authentication.

## Features

- **Dashboard**
  - Open cases by status
  - Upcoming statute-of-limitations (SOL) deadlines
  - Overdue medical records requests
  - Total medical specials (billed, paid, outstanding) per case
- **Clients / claimants** - demographics, injury date and injury type (e.g. lumbar disc herniation); full CRUD
- **Cases / matters** - case number, assigned attorney, paralegal, status
  (Intake, Treatment, Demand, Litigation, Settled, Closed) and SOL date; full CRUD.
  A warning is shown whenever the SOL date is within 90 days (or has passed) for an open case.
- **Case list search and filter** - free-text search (case number, client, attorney, paralegal) plus status filter
- **Medical providers** - spine surgeons, chiropractors, imaging centers, pain management, physical therapy,
  primary care; full CRUD with type/name filter
- **Case detail page** - aggregates the claimant, treatments and visits (provider, date, procedure, billed, paid,
  lien flag), records requests (requested date, provider, status Pending/Received/Overdue, follow-up date),
  case notes, and a medical specials summary (billed, paid, outstanding, lien balance)
- **Add from the case page** - treatments, records requests and notes can be added inline; pending requests
  can be marked as received
- Data-annotation validation (server-side and client-side via jQuery Validation)

## Technology

- .NET 6 (`net6.0`), ASP.NET Core MVC, minimal hosting model (`Program.cs`)
- Entity Framework Core 6 InMemory provider (`Microsoft.EntityFrameworkCore.InMemory` 6.0.36) with seed data
- Bootstrap 5 and Bootstrap Icons loaded from a CDN (internet access is needed in the browser for styling)
- Nullable reference types and implicit usings enabled

## How to run

Prerequisite: the **.NET 6 SDK** (or a newer SDK that can target `net6.0` with the .NET 6 runtime installed).

From the repository root (the folder containing `bSpine.sln`):

```bash
dotnet run --project bSpine
```

Or open `bSpine.sln` in Visual Studio 2022 and press F5.

By default the app listens on `https://localhost:7180` and `http://localhost:5180`
(see `bSpine/Properties/launchSettings.json`).

The database is in memory and is re-seeded every time the application starts, so any changes you make are
lost on restart. Seed dates are relative to the current date so that the SOL warnings and overdue requests
are always visible on the dashboard.

## Notes

- There is no authentication or authorization in this demo.
- To switch to a persistent database, replace `UseInMemoryDatabase` in `Program.cs` with a relational provider
  (for example SQL Server) and add migrations.
